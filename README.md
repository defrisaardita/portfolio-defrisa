# Defrisa Ardita Putri — Portfolio Website

Portfolio website statis yang dibuat berdasarkan CV Defrisa Ardita Putri.

## Isi
- `index.html` — struktur dan konten website
- `style.css` — desain responsif + animasi
- `script.js` — menu mobile + reveal animation

## Sebelum dipublikasikan
1. Buka `index.html`.
2. Cari `YOUR_EMAIL@example.com`.
3. Ganti dengan email profesional Anda.
4. Jika punya LinkedIn/GitHub/nomor WhatsApp, tambahkan pada bagian Contact.

## Cara melihat di komputer
Klik dua kali `index.html`, atau gunakan VS Code + extension Live Server.

## Cara membuatnya bisa diakses semua orang
### Opsi 1 — GitHub Pages
1. Buat akun/login GitHub.
2. Buat repository baru, misalnya `portfolio-defrisa`.
3. Upload `index.html`, `style.css`, dan `script.js`.
4. Masuk Settings → Pages.
5. Pilih Deploy from a branch → `main` → `/root`.
6. Simpan. GitHub akan memberikan URL publik.

### Opsi 2 — Netlify
1. Buka Netlify.
2. Login.
3. Pilih Add new site / Deploy manually.
4. Upload folder portfolio ini.
5. Netlify akan memberi URL publik.

Website ini tidak membutuhkan database atau server.
